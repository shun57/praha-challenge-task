## 課題2

### 共通点

- コンポーネントベースの考え方（再利用、ツリー、データ共有）
- SSR可能
- 仮想DOMの利用
- リアクティブなデータバインディング

### 差異

- Hooks:React ※Vueでもmoutedなどライフサイクルフックはある
- 単一ファイルコンポーネント(SFC):Vue
- OptionsとCompositionの２つのスタイル：Vue
- JSX:React * テンプレート構文：Vue
